# Format: `<prefix> <component>`, whitespace-separated, one pair per line, `#` comments.
# A `*` in a prefix is a non-empty run within one path segment; a single `*` in the
# component name is replaced by the text that the prefix `*` matched.
# Longest literal prefix wins (the `*` characters do not count); a tie goes to the first line.
# A path with no matching prefix maps to its first path segment.
