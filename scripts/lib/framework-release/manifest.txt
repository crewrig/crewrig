# manifest.txt — the contents of the framework release archive (spec 0310 R3; spec 0288 R8).
#
# One repository-relative path per line, forward slashes, no leading slash, no `..`, no trailing slash.
# An entry names a FILE, or a DIRECTORY that stands for every file beneath it. The archive carries
# those files under the same flat repository-relative paths and nothing else. The build fails when an
# entry is absent from the build output. A file is shipped only when git tracks it, except beneath
# `dist/`, the git-ignored output of `node scripts/build-components.ts`.
#
# A mapped line `<archive-path> <- <source>` ships one git-tracked file (no `dist/` exemption) under another
# archive path; two entries that give one archive path from different sources fail the build (spec 0315 R11).
#
# What `setup` reads and the hooks it wires (spec 0256, spec 0288 R8). The commands of the organization config
# repository, `init` (WP3) and `build`, `setup` and `update` (WP4, spec 0315), are served by the entry point and
# the modules of its closure, listed below.
