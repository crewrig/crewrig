# Antigravity CLI — cleanup superseded ~/.gemini/GEMINI.md context file

## ADDED

**Requirements.**

1. **Requirement 8 — setup scripts cleanup superseded `~/.gemini/GEMINI.md`.**
   `scripts/setup-antigravity-interactive.sh` SHALL detect and remove any legacy
   or superseded `~/.gemini/GEMINI.md` context file generated by earlier crewrig
   setup versions (identified by the `<!-- crewrig-section:` header marker) during
   setup execution, preventing Antigravity CLI from loading duplicate stale rules
   from `~/.gemini/GEMINI.md` alongside `~/.gemini/config/AGENTS.md`.
2. **Requirement 9 — Gemini setup script symmetry.**
   `scripts/setup-gemini-interactive.sh` SHALL likewise detect and remove any
   legacy `~/.gemini/GEMINI.md` bearing the `<!-- crewrig-section:` header marker,
   ensuring no lingering superseded concatenation remains in `~/.gemini/` where
   Gemini CLI loads modular context files enrolled in `context.fileName`.

**Scenarios.**

**Scenario:** Superseded GEMINI.md removed on Antigravity setup

Given an environment where a legacy `~/.gemini/GEMINI.md` containing `<!-- crewrig-section:` exists
When the user runs `setup-antigravity-interactive.sh`
Then `~/.gemini/GEMINI.md` is removed,
  `~/.gemini/config/AGENTS.md` is generated with the active configuration,
  and Antigravity CLI loads exclusively `~/.gemini/config/AGENTS.md`.

**Scenario:** Unmarked user GEMINI.md preserved

Given an environment where `~/.gemini/GEMINI.md` exists but does not contain the `<!-- crewrig-section:` marker
When `setup-antigravity-interactive.sh` runs
Then `~/.gemini/GEMINI.md` is not removed or modified,
  and `~/.gemini/config/AGENTS.md` is generated normally.

**Scenario:** Superseded GEMINI.md removed on Gemini setup

Given an environment where a legacy `~/.gemini/GEMINI.md` containing `<!-- crewrig-section:` exists
When the user runs `setup-gemini-interactive.sh`
Then `~/.gemini/GEMINI.md` is removed,
  and modular context files are deployed to `~/.gemini/` and enrolled in `settings.json`.
