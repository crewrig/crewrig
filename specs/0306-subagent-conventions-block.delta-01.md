# Subagent conventions block inlined into every emitted agent

*Delta 01 of `specs/0306-subagent-conventions-block.md`. Source: issue #1989, a `spec`-class finding from DEV. Requirement R19 of the parent asks for a dedicated capability entry, GitHub job and GitLab job for `scripts/check-subagent-conventions.ts`. The implementation measured 9,160 lines across the three CI surfaces (`ci/ci-capabilities.yml`, `.gitlab-ci.yml`, the workflow files) with a dedicated job, above the hard cap of 9,100 lines of spec 0287 R13, which states that the change is then rejected and the design reduced. The precedent is delta 01 of spec 0289 (#1863): its agent citation check joined an existing governance job for 4 lines. This delta amends R19 so that the check joins an existing job. Version 2.0.0, a MAJOR bump: R19 is modified in a way that invalidates the in-flight implementation. Requirements R1 to R18 and R20 to R24, and every scenario, are unchanged: a search of the parent for `capability`, `job` and `R19` finds the dedicated entry only in R19. This delta opens no question.*
