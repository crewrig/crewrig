# Friction reporting

A tool, a prompt or a workflow that misleads you will mislead the next agent the same way, and the maintainers only learn of it if someone says so. Reporting costs one short tag; staying silent costs every later session.

- When something in the workflow misleads or blocks you (the user corrects an action you just took, a rule forces an awkward workaround, a tool surprises you a second time, a documented step is missing or contradictory), use the `harness-report` skill to tag it.
- Tag it at the moment it happens and then carry on. Do not stop the user's task for it, and do not wait for an acknowledgement.
- If you are unsure whether something qualifies, tag it. Curation discards noise, whereas a friction nobody reported stays in place.
