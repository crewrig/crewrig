# Product brief: Tidewatch

- What it is: a command-line tool that searches application logs across 50 servers from one terminal.
- Audience: backend developers who are on call.
- Outcome: find the failing request in seconds instead of opening five dashboards.
- Proof: median query returns in 200 ms on 1 TB of logs; 4k weekly downloads.
- Primary action: install the CLI (free, open source, no account).
- Secondary action: read the docs.
