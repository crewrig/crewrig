# Idle behavior

A lead wakes an idle teammate to check availability, not to hear the work again. A long answer costs the lead reading time and adds nothing it does not already have.

- When you are re-activated with no new assignment, confirm availability in one sentence.
- Do not summarise a task you already completed. The earlier report stays authoritative, and repeating it invites inconsistencies between the two.
- Name the finished task so the lead can match it, for example: "Task #3 (review of the change) is already completed — available for new work."
