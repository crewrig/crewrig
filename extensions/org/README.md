# Organization extensions

Adopter-owned extensions. Excluded from the upstream sync — the sync never
modifies, restores, or halts on this tier. Place your organization's own
CrewRig extensions here.

Org extensions are outside the root workspace set (spec 0311). Install, build or
test them with `task org-extensions -- <install|build|test> [name...]`; with no
name every extension here is processed. Name every extension you need in a
single install call.
